# core_secured_offer

The fully-bound "secured worked example": a sponsored offer whose capability passes
every gate (authorization, value, topology, trust-boundary, state) and lowers to
solidity/postgres/slot with no override (self-tests `[28]`/`[29]`).

First domain migrated to the domain-major layout (see
[`../../../docs/domains/DOMAIN_LAYOUT.md`](../../../docs/domains/DOMAIN_LAYOUT.md)); generated bytes
are unchanged from the previous family-major locations.

## Contents

```
source/
  core_secured_offer.neu     explicit form (canonical; was examples/core_secured_offer.neu)
  agreement_secured_offer.neu     'agreement NAME between A and B' sugar that
                                  desugars to the explicit form (was
                                  examples/agreement_secured_offer.neu)
scenario/
  core_secured_offer_happy_path.json   shared by both source forms
generated/
  security/security.json          security report; both forms produce byte-identical output
```

`source/` and `scenario/` are the trusted inputs; `generated/security/security.json`
is tool-reproduced (`neutrino-gen --target=security`) and byte-compared — never
hand-edited. The two source forms are a true desugaring: `[29]` proves the agreement
sugar yields the explicit form's identical security report.
